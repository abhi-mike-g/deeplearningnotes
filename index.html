1.1 What is being learned?

In one line

Learning chooses a function from data; deep learning chooses a composition of many trainable transformations.

The problem

Hand-written rules work when the relationship is simple and explicit. They become brittle when the input is an image, a sentence or a noisy measurement. A model replaces the rule book with a family of functions f(x; θ), and training chooses the parameters θ using examples. The goal is useful behaviour on new examples, not merely a small error on the examples already seen.

Mechanism

Input, target, prediction and objective

An input x contains the information available at prediction time. A target y is the answer supplied during supervised training. The prediction ŷ = f(x; θ) is what the model produces. A loss ℓ(ŷ,y) measures disagreement for an example; an objective J usually averages this loss over a dataset and may add a regularisation penalty. The optimiser changes θ to reduce J. These roles remain the same for linear regression, a convolutional network and a recurrent network.

Parameters are fitted quantities: weights, biases and learned normalisation scales. Hyperparameters specify how fitting happens or which family is fitted: number of layers, learning rate, batch size and regularisation strength. The distinction is operational. A number is not a hyperparameter merely because it is written using a Greek letter.

SettingData and targetWhat a useful output means
Supervised regressionPaired x and real-valued yPredict a temperature, score or depth
Supervised classificationPaired x and class labelsEstimate a binary or multiclass label distribution
Unsupervised learningInputs without supplied task labelsFind clusters, a compressed representation or a data distribution
Self-supervised learningTargets constructed from the input dataPredict a masked token or reconstruct a clean input

An autoencoder is often described as unsupervised because it needs no human labels; its training nevertheless has a reconstruction target. A generative model learns enough about a distribution to produce samples. A classifier primarily predicts a label conditional on an input. These are different tasks, not a ranking of intelligence.

Why depth helps

An image model can compose local edge detectors into shapes and then into object evidence. A sequence model can combine a current token with a state summarising its context. Depth is the number of successive transformations; width is the number of units in a layer. There is no universal mathematical rule that a network becomes “deep” only after exactly three hidden layers. State the actual architecture.

For the 2025 supervised-versus-unsupervised question, explicitly mention both the presence of labels and the learning goal. Then give one example of each: disease classification from labelled records, and customer clustering from purchase features without customer-group labels.

Where the numbers come from

The course’s task examples are illustrations, not performance measurements. A five-class single-label classifier usually has five output scores; a binary classifier can use one sigmoid output. An image with H×W pixels and C channels has HWC scalar input values before the batch dimension is added.

Failure mode

A feature unavailable at inference, such as a diagnosis made after treatment, can leak the answer into training. Excellent measured performance then reflects the leakage. Always describe exactly when each input becomes available.

Try it before revealing the answer

Is a model with a continuous output necessarily linear?

No. Regression describes the target type. A deep nonlinear network can perform regression.

Why is clustering not the same as classification?

Clustering chooses groups from input structure without given class targets. Classification learns a mapping to supplied labels. A cluster need not coincide with a meaningful labelled class.

1.2 Vectors, matrices and a consistent notation

In one line

Checking dimensions before multiplying is the fastest way to detect a wrong network calculation.

The problem

A diagram can show dozens of arrows, while an equation hides them in one matrix. Errors occur when a matrix row is mistaken for a source neuron, a batch axis is mistaken for a feature axis, or a weight index is interpreted using a convention different from the question.

Mechanism

The convention used throughout this notebook

Inputs and activations are column vectors. At layer ℓ, z⁽ℓ⁾ is the pre-activation, a⁽ℓ⁾ is the post-activation, and a⁽⁰⁾ = x. Rows of W⁽ℓ⁾ are destination neurons; columns are source neurons. Thus W⁽ℓ⁾ has shape nℓ × nℓ₋₁. The bias b⁽ℓ⁾ has nℓ entries.

Open the equations / numerical layout
z⁽ℓ⁾ = W⁽ℓ⁾a⁽ℓ−1⁾ + b⁽ℓ⁾
a⁽ℓ⁾ = φℓ(z⁽ℓ⁾)
zⱼ⁽ℓ⁾ = Σₖ Wⱼₖ⁽ℓ⁾ aₖ⁽ℓ−1⁾ + bⱼ⁽ℓ⁾

For two inputs and three hidden neurons, W has three rows and two columns. Each row contains the two arrows entering one hidden neuron. The matrix product produces three weighted sums. A bias is added once per receiving neuron, not once per incoming edge. It can also be drawn as a weight attached to a constant input of one.

The 2026 paper defines wᵢⱼₖ as layer i, destination j, source k. Its w₁₂₂ therefore means the connection from input x₂ to the second neuron of hidden layer 1. Some lecture slides reverse the last two verbal index roles. Follow the definition in the question, then translate it into this row/column convention. Do not infer the meaning of an index from its position alone.

Matrix multiplication is not elementwise multiplication. If A is m×n and B is n×k, AB is m×k. In contrast A⊙B multiplies corresponding entries and requires compatible shapes. Gates in an LSTM use ⊙; a dense layer uses a matrix product. The dot product of equal-length vectors is a scalar sum of pairwise products.

A small shape audit

For x = [2,3]ᵀ, W = [[1,−1],[0.5,2],[−2,1]], b = [0,1,−1]ᵀ, Wx+b = [−1,8,−2]ᵀ. The calculation is three separate dot products. Applying a rectified linear unit gives [0,8,0]ᵀ. The shape remains 3×1; an elementwise activation changes values, not the number of entries.

Where the numbers come from

The sizes here come from the declared architecture. They are not tuning defaults. A transpose changes m×n to n×m; it does not change the number of parameters. For floating-point storage, number of scalars × bytes per scalar gives raw tensor storage, before gradients and optimiser states.

Failure mode

Writing vᵀh when v is already a row vector produces an invalid shape. Likewise, summing all entries of a weight matrix instead of taking row-wise dot products destroys the distinction between neurons. Name the shape beside each intermediate result in an exam.

Try it before revealing the answer

A layer takes 7 features and outputs 4 values. What are W, b and z shapes?

W is 4×7, b is 4×1, and z is 4×1 for a single input. It contains 28 weights and 4 biases.

Why is a gate product h⊙r different from Wh?

The gate scales each existing coordinate individually; the matrix can mix information across different coordinates.

1.3 Derivatives, gradients and the chain rule

In one line

A derivative measures sensitivity; backpropagation combines local sensitivities along every route to the loss.

The problem

Trying arbitrary weights is impractical even for a small network. We need to know which changes will decrease the loss. Calculus supplies local information: how much the loss changes per small change in each parameter. It does not guarantee that a finite update will improve the loss, which is why the learning rate matters.

Mechanism

From one variable to many

For a scalar function f(w), the derivative f′(w) is the slope of its tangent. For a scalar loss J(w₁,…,wₙ), the gradient ∇J is the vector of partial derivatives. The partial derivative with respect to w₁ holds the other independent parameters fixed. To first order, J(w+Δw) ≈ J(w)+∇JᵀΔw. Choosing Δw = −η∇J makes the linear prediction decrease by η‖∇J‖² for η>0.

tanh(x)1−tanh²(x)Derivative approaches zero in saturated tails
σ(x)σ(x)(1−σ(x))Maximum slope is 1/4 at x=0
max(0,x)0 for x<0; 1 for x>0A nonpositive branch may transmit no gradient

At the ReLU kink x=0 the ordinary derivative is undefined. Implementations choose a subgradient, commonly zero. State this if asked for a mathematically complete derivative; the usual exam table’s “zero for x≤0” is an implementation convention.

The chain rule and branches

If z=wx+b, a=σ(z), and L=½(a−y)², then ∂L/∂w=(a−y)a(1−a)x. The factors are respectively the loss sensitivity to the prediction, activation sensitivity to its input, and weighted-sum sensitivity to w. Bias has the same formula without x because ∂z/∂b=1.

If a hidden neuron influences two later neurons, the loss receives two contributions. Add those contributions before applying the local derivative. This is the central difficulty in the 2026 gradient problem: there are two paths from the requested weight to the output, and both must be included.

A numerical gradient check

Evaluate L at w+ε and w−ε while keeping all other parameters unchanged. The central difference [L(w+ε)−L(w−ε)]/(2ε) approximates ∂L/∂w. An ε around 10⁻⁵ is useful in these small double-precision examples, but it is not a universal constant. A very small ε magnifies subtraction rounding; a very large one measures curvature over an interval rather than the local derivative. Avoid testing exactly at a nondifferentiable kink.

Convexity describes the entire function, not the direction of one slope. A differentiable convex function lies above every tangent plane. Squared loss is convex in a linear model’s parameters, but the same loss composed with a multilayer nonlinear network is generally nonconvex. A linear function is both convex and concave.

Where the numbers come from

The factor ½ in the example cancels the 2 from differentiating a square. It changes gradient scale without changing the minimising parameters. If an objective averages N samples, its derivative also contains 1/N.

Failure mode

Using the loss value instead of its derivative in an update is wrong: x−ηf(x) is not gradient descent on f. Updating output weights before calculating hidden gradients also mixes two different network states; compute all gradients from the same forward pass.

Try it before revealing the answer

For f(x)=x²+4x+1, give one update with η=0.1.

xₜ₊₁=xₜ−0.1(2xₜ+4). The derivative, not f(xₜ), determines the update.

Does a zero gradient prove a global minimum?

No. It can mark a local minimum, maximum, saddle point or flat region. Additional structure, such as convexity, is needed for a stronger conclusion.

1.4 Norms, distances and feature scaling

In one line

A norm measures size; the chosen geometry determines what counts as a large error, distance or weight.

The problem

A distance-based classifier can be dominated by a feature measured in thousands while another feature lies between zero and one. A weight penalty also needs a precise definition of “large”. Norms make those choices explicit and reveal why changing units can change the result.

Mechanism

For v=[v₁,…,vₙ], the L1 norm is Σ|vᵢ|, the L2 norm is √Σvᵢ², and the L∞ norm is max|vᵢ|. For v=[3,−4], they are 7, 5 and 4. Squared L2 is 25 and is not the L2 norm itself. The common ridge penalty uses the square, because its derivative is simple and smooth.

Euclidean distance is ‖x−z‖₂. Manhattan distance is ‖x−z‖₁. A distance is small only relative to the measurement scale. To standardise feature j, compute its mean μⱼ and standard deviation sⱼ on the training data, then use (xⱼ−μⱼ)/sⱼ for training, validation and test examples. Recomputing the statistics on the test set leaks information and changes the meaning of the feature space.

For a matrix A, the Frobenius norm is √Σᵢⱼ Aᵢⱼ². It measures all entries together. This appears in the contractive-autoencoder penalty on the encoder Jacobian. A vector’s L∞ norm is a perfectly valid convex regulariser; it is simply less common than L1 and squared L2. Away from ties, only the component attaining the largest absolute value determines its gradient. That behaviour differs from the distributed smooth shrinkage of L2 and the sparsity preference of L1.

How to answer the 2025 norm question

Give all three definitions with the absolute values and square root in the correct places. Then explain that L1 encourages sparse solutions, squared L2 encourages distributed small weights, and L∞ controls the largest coefficient. Do not claim L∞ “cannot be differentiated anywhere” or “cannot be used for regularisation”. Nonsmooth convex penalties can be optimised with subgradient or proximal methods.

The geometry also connects to gradient clipping: clipping by global L2 norm preserves a gradient vector’s direction, whereas clipping each coordinate independently generally rotates it.

Where the numbers come from

For v=[3,−4], L2=5 follows from the 3–4–5 triangle. These are exact arithmetic examples. Standardisation has an additional policy for zero-variance features: drop the feature or use a guarded scale; dividing by zero is not meaningful.

Failure mode

L1 sparsity is a property of the penalised optimum and appropriate optimisation. Naive fixed-step subgradient descent can bounce across zero instead of landing on it. Likewise L2 does not mathematically forbid zero coefficients; it generally does not induce sparsity.

Try it before revealing the answer

L1=5; L2=3; L∞=2. Squared L2=9.

Why must standardisation statistics be fitted only on training data?

They are part of the fitted pipeline. Using held-out data to estimate them gives the learning process information about the evaluation set.

2.1 Events, distributions and expectations

In one line

Probability assigns mass to events; a continuous density gives probability only after integration over an interval.

The problem

A noisy dataset cannot be described adequately by a single deterministic prediction. We need a language for variation, conditional statements and uncertain outcomes. Confusing a probability density with a probability, or a conditional probability with its reverse, leads directly to wrong exam answers.

Mechanism

A sample space Ω contains possible outcomes; an event is a subset. Probabilities are nonnegative, P(Ω)=1, and disjoint events add. In general P(A∪B)=P(A)+P(B)−P(A∩B). Independence means P(A∩B)=P(A)P(B). Mutual exclusivity means the intersection is empty. Two events with positive probabilities cannot be both independent and mutually exclusive.

A random variable maps outcomes to numbers. Its distribution specifies how probability is assigned to those numbers. A Bernoulli variable takes 0 or 1, with P(X=1)=p and P(X=0)=1−p. A categorical variable chooses one of K classes with probabilities summing to one.

A uniform distribution on [0,0.2] has density 5. Its area is 5×0.2=1, so there is no contradiction. P(0.05≤X≤0.1)=5×0.05=0.25. This supplies more than the three distinctions requested in 2025 Q18.

Mean and spread

Expectation is a probability-weighted mean: E[X]=Σxp(x) or ∫xf(x)dx. Variance is E[(X−μ)²]=E[X²]−μ². Standard deviation is its square root and has the same units as X. For Bernoulli(p), E[X]=p and Var(X)=p(1−p). For a fair die the mean is 3.5, even though 3.5 is not a possible roll.

The normal distribution has density f(x)=exp[−(x−μ)²/(2σ²)]/(σ√(2π)), with σ>0. It is symmetric around μ; mean, median and mode coincide. Its support is the whole real line and its total area is one. The normal distribution is a modelling assumption, not something every real dataset automatically satisfies.

Where the numbers come from

The normalising constant σ√(2π) ensures total area one. The Gaussian maximum-likelihood variance uses divisor N; the common unbiased sample-variance estimator uses N−1. They solve different statistical problems, so state which estimator is being requested.

Failure mode

A histogram bar’s height may be a count, a relative frequency or a density. Read its normalisation before interpreting it. Also, a PDF value of 0.8 does not mean an 80% probability of one exact real-valued observation.

Try it before revealing the answer

Can a normal random variable be negative?

Yes. Its support is all real values, although the probability of negative values can be tiny for some means and standard deviations.

If A and B are independent with probabilities 0.4 and 0.5, what is P(A∩B)?

0.4×0.5=0.2. Independence is what permits multiplication of the marginal probabilities.

2.2 Bayes’ theorem and the base-rate trap

In one line

A positive observation is convincing only relative to how common the underlying cause was before the observation.

The problem

P(positive | disease) answers how often a test detects disease. The question P(disease | positive) asks how many positive results are genuine. These are different conditional probabilities. A low disease prevalence can make false positives outnumber true positives even when a test is reasonably accurate.

Mechanism

Conditional probability is P(A|B)=P(A∩B)/P(B), provided P(B)>0. Writing the joint probability in both orders gives Bayes’ theorem. For a binary cause D, use the law of total probability to expand the denominator.

Open the equations / numerical layout
P(D | +) = P(+ | D)P(D) / P(+)
P(+) = P(+ | D)P(D) + P(+ | not D)P(not D)

The exact 2025 example

The paper gives prevalence 0.05, sensitivity 0.9 and false-positive rate 0.1. The true-positive contribution is 0.9×0.05=0.045. The false-positive contribution is 0.1×0.95=0.095. Total positive probability is 0.14. Therefore P(D|+)=0.045/0.14=9/28≈0.321429, or 32.14%.

Imagine 1,000 people with exactly those proportions as an explanatory population. Fifty have the disease, of whom 45 test positive. Of 950 without it, 95 test positive. There are 140 positives and only 45 genuine cases. This count argument and the algebra are the same calculation. The counts are illustrative expected frequencies, not measurements from a clinical dataset.

An exam answer that exposes the denominator

Name the prior P(D), likelihood P(+|D), and evidence P(+). Substitute both branches of the evidence explicitly. Finish with a probability or percentage and a sentence interpreting it. Merely writing “90%” repeats the sensitivity and does not answer the question.

The same mechanism supports spam filtering, fault diagnosis and the Naive Bayes classifier. The word “Bayesian” describes updating a prior with evidence; it does not eliminate the need for a defensible likelihood model.

Where the numbers come from

All three probabilities in this worked example are specified in 2025 Q13. The posterior is derived from them. In the lab, changing prevalence alone changes the posterior even if sensitivity and false-positive rate are unchanged.

Failure mode

If the evidence has zero probability under the model, the conditional probability is undefined. A classifier should not silently return zero or one. The lab reports an undefined posterior when both positive branches have zero probability.

2.3 Maximum likelihood and maximum a posteriori estimation

In one line

Maximum likelihood chooses parameters that make the observed data most plausible; MAP also weights those parameters by a prior.

The problem

Different parameter settings can produce the same kind of data with different probabilities. Estimation needs a rule for choosing among them. A common verbal mistake reverses P(data|parameter) into P(parameter|data), confusing likelihood with posterior probability.

Mechanism

For independent and identically distributed observations D={x₁,…,xN}, the likelihood is ℒ(θ)=∏ᵢp(xᵢ|θ). The data are fixed while θ varies. Maximum likelihood estimation (MLE) chooses argmaxθ ℒ(θ). A likelihood is not generally a normalised probability distribution over θ.

Logarithms preserve the location of a maximum because log is strictly increasing. They turn products into sums and prevent products of many tiny probabilities from underflowing. Thus maximum log-likelihood and minimum negative log-likelihood give the same parameter estimate.

Coin-toss derivation

For H heads and T tails, L(p)=pᴴ(1−p)ᵀ for a particular sequence. If the observation is only the count, a binomial coefficient multiplies this expression; it does not depend on p and therefore does not change the optimum. The log-likelihood is H ln p+T ln(1−p). Its derivative is H/p−T/(1−p). Setting it to zero yields p̂=H/(H+T).

In 2026 Q2, the first batch has 3 heads and the second 7 heads, each from 10 tosses. Combined evidence gives H=10, N=20, so p̂=0.5. For unequal batch sizes, average the counts, not the batch estimates with equal weight. If all tosses are heads, the maximum is at the boundary p=1; the interior derivative derivation alone is insufficient.

Add a prior

Maximum a posteriori (MAP) estimation chooses argmaxθ p(θ|D), proportional to p(D|θ)p(θ). In logs this is a likelihood term plus log prior. With a constant positive prior over the relevant parameter domain, MAP and MLE have the same maximisers. A restricted uniform prior can still exclude an unconstrained MLE, so the domain qualification matters.

A Beta(α,β) prior for a Bernoulli probability gives posterior Beta(H+α,T+β). If both posterior shape parameters exceed one, its mode is (H+α−1)/(N+α+β−2). The posterior mean is (H+α)/(N+α+β), a different estimator. For H=7,T=3,α=β=2, MLE=0.7, MAP=8/12≈0.6667, posterior mean=9/14≈0.6429.

Where the numbers come from

The coin MLE comes from differentiating the likelihood; it is not a memorised averaging rule. Beta(1,1) is uniform on [0,1]. The symbols α and β represent prior shape parameters here, not learning rate or momentum.

Failure mode

“Maximise the probability of the parameters given the data” defines MAP, not MLE. The first statement in 2026 Q1 is therefore false; its uniform-prior statement is true under the common support assumption. Prior choice can dominate small datasets, so always disclose it.

2.4 Logistic regression and likelihood-derived losses

In one line

The sigmoid turns a real score into a Bernoulli probability, and its log-odds remain linear in the features.

The problem

A raw linear score z=wᵀx+b can be −3 or 2.5, which cannot be probabilities. A hard threshold can classify it, but discards how strongly the model supports the decision and supplies no ordinary useful derivative through the threshold. Logistic regression models a probability smoothly.

Mechanism

Set p=σ(z)=1/(1+e⁻ᶻ). Then 0<p<1 for finite z, p=0.5 at z=0, and p rises monotonically with z. The odds are p/(1−p)=eᶻ, so log[p/(1−p)]=wᵀx+b. Each coefficient changes log-odds linearly while the probability changes nonlinearly.

For a threshold τ, predict the positive class if p≥τ. The conventional τ=0.5 corresponds to z≥0. Another threshold corresponds to z≥ln[τ/(1−τ)]. The decision boundary is still a hyperplane in the original features. A nonlinear probability transformation does not by itself give logistic regression an arbitrary nonlinear class boundary.

Derive binary cross-entropy

For a binary target y, the Bernoulli likelihood is pʸ(1−p)¹⁻ʸ. Its negative logarithm is ℓ=−y ln p−(1−y)ln(1−p), the binary cross-entropy (BCE). For y=1 it is −ln p; for y=0 it is −ln(1−p). Averaging over examples gives a dataset loss. A confident wrong prediction receives a large penalty.

For Gaussian regression noise y=f(x;θ)+ε with ε distributed as a zero-mean normal of fixed variance σ², negative log-likelihood equals a constant plus Σ(y−f(x;θ))²/(2σ²). This is why least squares is connected to a probabilistic assumption. It is not why every error distribution must be Gaussian.

Two complete reasons for 2026 Q13

First, bounded output ensures valid class probabilities, unlike unbounded raw linear scores. Second, sigmoid provides a smooth probability model with a linear log-odds interpretation and a clear threshold decision rule. Include the equations p=σ(z) and log[p/(1−p)]=z. Avoid saying a linear score “cannot classify”: it can be thresholded, but it is not itself a probability model.

Where the numbers come from

At z=0.5, sigmoid is 0.622459 and tanh is 0.462117, the values tested in 2026 Q9. For a correct positive prediction p=0.8, BCE=−ln(0.8)≈0.223144. Logarithms in this notebook are natural logarithms, so losses are measured in nats.

Failure mode

Applying sigmoid twice changes the model. If a loss accepts logits, give it raw scores; do not also transform them outside the loss. For large negative logits and y=1, calculating log(sigmoid(z)) naively can underflow. The stable formulation is developed in losses.

3.1 Least squares, including a fixed intercept

In one line

The least-squares solution depends on which coefficients are free; a fixed intercept must remain fixed during the derivation.

The problem

Fitting a line is a small version of neural-network training: choose parameters, evaluate predictions, define a loss, and optimise it. The 2025 paper adds a trap by specifying the intercept c=1. Using the usual formula that estimates both slope and intercept solves a different problem.

Mechanism

For ŷᵢ=mxᵢ+c, let S(m,c)=Σᵢ[yᵢ−(mxᵢ+c)]². Residuals are signed errors; squaring prevents positive and negative residuals cancelling. A large residual contributes disproportionately. The fitted line minimises vertical squared errors, not perpendicular distances to the line.

3.2 k-nearest neighbours and local voting

In one line

k-nearest neighbours predicts from nearby stored examples; k determines how local the decision is.

The problem

A simple classifier can use the idea that similar inputs tend to share labels without learning an explicit equation for the boundary. The cost is deferred to prediction time: compare the query with stored training examples, select neighbours, and aggregate their labels.

Mechanism

For classification, compute distances to every training point, sort them, choose the k nearest, and take a majority vote. For regression, average their targets, possibly with distance weights. A tie-breaking rule must be declared. An odd k helps avoid binary vote ties but does not eliminate equal-distance ties or multiclass vote ties.

For query A=(5,5), squared distances to P1–P7 are 13,4,2,5,25,20,10. The first three neighbours are P3, P2, P4, giving labels 0,0,1 and prediction 0. Square roots preserve ordering, so squared distances suffice for ranking.

For query B=(7,3), squared distances are 25,20,10,9,37,20,26. The nearest label is 1, while the three nearest labels are 1,0,0 and vote for 0. This demonstrates how k changes a prediction using exactly the same data. The lab includes the dataset explicitly and breaks equal-distance ties by point order.

Bias, variance and cost

With k=1, one noisy example can create a tiny decision region: low training error and high sensitivity to the sample. Increasing k usually smooths the boundary, increases bias and decreases variance. At k=N with unweighted voting, every query receives the global majority class. This is the limit tested in 2025 Q6. It is a tendency, not a universal monotonic test-error law.

There is no parameter-fitting phase in the usual lazy-learning sense, but storing data and building a search index are still preparation. A naive query takes O(Nd) distance arithmetic for N points in d dimensions, plus selection work. Exact or approximate indexes can change the cost. In high dimensions, distances may become less informative and neighbour search becomes harder. Scale features using the training statistics from the norm chapter.

Where the numbers come from

The seven-point example follows merged pp. 167–172. Counts are labels, not probabilities calibrated by a generative model. A vote fraction can be used as a score, but should not automatically be interpreted as a well-calibrated probability.

Failure mode

One feature with a large numerical scale can dominate every distance. Also, include the query itself in a training-set check and 1-neighbour classification trivially appears perfect. Use held-out evaluation or an explicit leave-one-out rule.

3.3 Naive Bayes: count, multiply, compare

In one line

Naive Bayes combines a class prior with feature likelihoods, assuming the features are conditionally independent given the class.

The problem

Directly estimating a probability for every combination of features requires many observations. Conditional independence reduces the problem to separate feature counts within each class. The approximation can be crude yet still support useful class decisions.

Mechanism

For features x₁,…,xd and class C, Bayes gives P(C|x) proportional to P(C)P(x|C). Naive Bayes approximates P(x|C) by ∏ⱼP(xⱼ|C). Independence is conditional on C, not a claim that the features are independent in the full population. Classification compares unnormalised scores sC=P(C)∏ⱼP(xⱼ|C), because the evidence P(x) is the same positive denominator for every class.

3.4 k-means as alternating minimisation

In one line

k-means alternates nearest-centroid assignment and mean recomputation, never increasing its squared-distance objective at either exact step.

The problem

Without labels, we can group observations around representatives. But both group membership and the representatives are unknown. k-means solves one while holding the other fixed, then swaps roles. It is an optimisation procedure, not a guarantee that the groups reflect the intended real-world categories.

Mechanism

The objective is J=Σᵢ‖xᵢ−μcᵢ‖², where cᵢ is a cluster assignment. Choose K initial centres. Assignment selects the smallest distance. The update sets each nonempty cluster’s centre to its arithmetic mean. Repeat until assignments or centres stabilise, an objective-change tolerance is met, or a maximum iteration count is reached.

For fixed centres, assigning a point elsewhere cannot decrease its distance. For fixed assignments, differentiating Σ‖xᵢ−μ‖² with respect to μ yields 2(nμ−Σxᵢ), whose zero is the mean. Both steps therefore cannot increase J. This monotonicity applies to the stated squared-distance objective and exact steps; it does not prove a global optimum.

3.5 Support vector machines: margins, slack and kernels

In one line

A soft-margin support vector machine trades margin width against quantified violations instead of demanding impossible perfect separation.

The problem

Many hyperplanes can separate a clean dataset. The support vector machine (SVM) chooses one with a large margin. Perfect separation can be impossible with overlapping labels, and forcing it on noisy data can make the classifier fragile. Slack variables turn the absolute constraint into a controlled penalty.

Mechanism

Use labels yᵢ∈{−1,+1}, score f(x)=wᵀx+b, and class sign(f(x)). The decision boundary is f(x)=0. Scaling w and b changes the score without changing the boundary, so the canonical constraints set yᵢf(xᵢ)≥1. The two margin planes f(x)=±1 are separated by 2/‖w‖₂. Minimising ½‖w‖² therefore maximises this width.

Open the equations / numerical layout
Hard margin:
minimise  ½‖w‖₂²
subject to yᵢ(wᵀxᵢ+b) ≥ 1 for every i

Soft margin:
minimise  ½‖w‖₂² + CΣᵢξᵢ
subject to yᵢ(wᵀxᵢ+b) ≥ 1−ξᵢ,   ξᵢ ≥ 0

The least feasible slack for a fixed w,b is ξᵢ=max(0,1−yᵢf(xᵢ)), the hinge loss. Let the signed margin be mᵢ=yᵢf(xᵢ). If m≥1, no violation is needed. If 0<m<1, the point is correctly classified but inside the margin. If m=0, it is on the decision boundary. If m<0, it is misclassified and needs slack greater than one. Kernels change the feature space

A kernel computes K(x,z)=φ(x)ᵀφ(z) without necessarily constructing φ explicitly. A linear separator in that feature space can be nonlinear in the original input coordinates. Examples include a linear dot product, polynomial kernel (xᵀz+c)ᵖ and Gaussian radial basis kernel exp(−γ‖x−z‖²). A kernel does not guarantee separability or accuracy; its scale and regularisation still matter.

4.1 McCulloch–Pitts units and the perceptron

In one line

A threshold neuron separates inputs by one hyperplane; learning its weights does not remove that geometric limitation.

The problem

An artificial neuron must combine evidence and decide whether it is sufficient to activate. The earliest threshold models do this with a sum and a cutoff. A perceptron adds adjustable weights, allowing different inputs to matter differently, but it still makes one linear separation.

Mechanism

A simple McCulloch–Pitts (MP) unit with binary excitatory inputs computes y=1 when Σxᵢ≥θ and 0 otherwise. The threshold convention matters: “greater than” and “greater than or equal to” give different boundary cases. For three unit-weight inputs, AND requires y=1 only when the sum is 3; θ=3 with the ≥ convention does this. The figure in 2026 Q7 has three inputs, so the answer is 3, not the two-input AND threshold 2.

A weighted perceptron computes z=wᵀx+b and thresholds it. For 0/1 labels one possible learning rule on a mistake is w←w+η(y−ŷ)x and b←b+η(y−ŷ). For ±1 labels, a common form is w←w+ηyx and b←b+ηy when y(wᵀx+b)≤0. State the label and tie conventions rather than mixing the two versions.

A one-step learning example

Let x=[1,0], target y=1, w=[0,0], b=−0.5 and η=0.2. With the 0/1 rule, prediction is 0. The correction is Δw=0.2[1,0] and Δb=0.2. New w=[0.2,0], b=−0.3. A single update need not already classify the example correctly; training revisits mistakes.

The perceptron convergence theorem guarantees a finite number of mistakes for a finite linearly separable dataset under its usual assumptions and update rule. It does not apply to inseparable data such as XOR in its original two features. It also does not say the perceptron finds a maximum-margin separator; that was the SVM objective in Part 03.

The biological analogy is limited. Inputs resemble incoming signals, weights resemble connection strengths, and activation resembles a response. A simple artificial neuron does not reproduce a biological neuron’s dynamics, chemistry or detailed architecture. The model is useful because of its mathematical behaviour.

Where the numbers come from

The AND threshold equals the number of required active unit-weight inputs only for this particular construction. With different weights, derive inequalities for every truth-table row. Threshold θ corresponds to bias b=−θ when the weighted sum is compared with zero.

Failure mode

Using a hard step activation in ordinary gradient-based backpropagation gives zero derivative almost everywhere and no derivative at the threshold. Train a perceptron with its own mistake rule, or use differentiable/piecewise differentiable activations for a neural network.

4.2 Why hidden layers solve XOR

In one line

Hidden units can build intermediate features whose combination separates a pattern that one line cannot separate.

The problem

XOR is positive at (0,1) and (1,0), negative at (0,0) and (1,1). Opposite corners of a square must share a label. No single straight line places both positive corners on one side and both negative corners on the other.

Mechanism

With a single threshold neuron and bias b, the positive cases require w₂+b≥0 and w₁+b≥0; negative cases require b<0 and w₁+w₂+b<0, using the positive-at-zero convention. Adding the positive inequalities gives w₁+w₂+2b≥0, hence w₁+w₂+b≥−b>0, contradicting the negative requirement. This proves the limitation rather than merely drawing it.

5.1 Match the output distribution to the loss

In one line

The output activation defines what a prediction means; the loss evaluates that prediction under the task’s target model.

The problem

A softmax is an activation, not a loss. Mean squared error is a loss, not a probability transformation. Mixing these roles can produce an output that looks plausible while training the wrong objective. The exam asks for these pairings explicitly.

Mechanism

TaskOutputTypical loss for one exampleInterpretation
Real-valued regressionLinear/identity(ŷ−y)² or ½(ŷ−y)²Fixed-variance Gaussian noise interpretation
Binary classificationOne sigmoid−y ln p−(1−y)ln(1−p)Bernoulli negative log-likelihood

Multiple independent binary labelsOne sigmoid per labelSum/mean of binary cross-entropiesSeparate Bernoulli outputs

For a one-hot multiclass target with correct class c, categorical cross-entropy (CCE) reduces to −ln p_c. With logits [2,1,0], softmax is approximately [0.665241,0.244728,0.090031]. If the first class is correct, loss is 0.407606; if the third is correct it is 2.407606. The same predictions receive a different loss because the target differs.

Softmax is a vector operation

Softmax normalises scores jointly: pᵢ=eᶻⁱ/Σⱼeᶻʲ. Increasing one logit changes every probability. Its derivative is ∂pᵢ/∂zⱼ=pᵢ(1[i=j]−pⱼ). The diagonal-only sigmoid derivative is not a substitute for this Jacobian. With normalised targets summing to one and CCE, the combined derivative simplifies to ∂L/∂z=p−y.

Stable evaluation

Subtract m=max z before exponentiation: pᵢ=exp(zᵢ−m)/Σexp(zⱼ−m). The common factor cancels, so probabilities do not change. For binary cross-entropy with logit z, use max(z,0)−yz+ln(1+exp(−|z|)). It avoids exponentiating a large positive number and avoids taking a logarithm of a rounded zero probability. The lab evaluates this stable expression.

Mean absolute error (MAE) is |ŷ−y| and has a constant-magnitude derivative away from zero, making it less sensitive to extreme residuals than squared error. Huber loss is quadratic close to zero and linear in the tails, with a threshold δ defining the transition. A loss must be chosen with the target, outlier behaviour and optimisation in mind.

Where the numbers come from

A uniform classifier over K classes has CCE=ln K. For K=5 it is 1.609438 nats. A balanced binary guess p=0.5 has BCE=ln 2≈0.693147. These are reference losses, not universal accuracy benchmarks.

Failure mode

Mean, sum and half-sum losses differ by scale. State the reduction over examples and output coordinates before differentiating. The loss value can be convex in predictions while remaining nonconvex in deep-network weights.

5.2 The four equations of backpropagation

In one line

Backpropagation computes the gradient efficiently by reusing each node’s accumulated sensitivity to the loss.

The problem

A parameter influences the loss through many intermediate operations. Recomputing every path independently repeats enormous amounts of work. Reverse-mode differentiation starts at the scalar loss, accumulates sensitivities backwards, and reuses them to obtain every parameter gradient.

Mechanism

Define δ⁽ℓ⁾=∂L/∂z⁽ℓ⁾, the derivative with respect to a layer’s pre-activations. It is not the activation error a−y except in special output/loss pairings. For elementwise activations, the four central equations are:

Open the equations / numerical layout
1. Output: δ⁽ᴸ⁾ = (∂L/∂a⁽ᴸ⁾) ⊙ φ′ᴸ(z⁽ᴸ⁾)
2. Hidden: δ⁽ℓ⁾ = (W⁽ℓ+1⁾ᵀ δ⁽ℓ+1⁾) ⊙ φ′ℓ(z⁽ℓ⁾)
3. Bias:   ∂L/∂b⁽ℓ⁾ = δ⁽ℓ⁾
4. Weight: ∂L/∂W⁽ℓ⁾ = δ⁽ℓ⁾ a⁽ℓ−1⁾ᵀ

The weight gradient is an outer product. Entry (j,k) is δⱼ⁽ℓ⁾aₖ⁽ℓ−1⁾: destination sensitivity times source activation. Its shape is nℓ×nℓ₋₁, exactly the shape of W. This shape check catches many missing transposes.

Why the hidden equation sums

One hidden activation sends information to every connected neuron in the next layer. Its effect on the loss is ΣⱼWⱼₖδⱼ. The transpose gathers those outgoing paths back into the source node. Multiplying by that source neuron’s activation derivative then converts sensitivity to a into sensitivity to z. A branch contributes even if it contains a negative weight; signs can cancel or reinforce.

For sigmoid plus half squared error, δout=(ŷ−y)ŷ(1−ŷ). For sigmoid plus BCE, the loss derivative and sigmoid factors simplify to δout=ŷ−y. For softmax plus CCE with normalised targets, the same vector form p−y holds, but its derivation uses the coupled softmax Jacobian. Do not delete the activation derivative when the pairing does not justify cancellation.

The complete training step

Cache every z and a during the forward pass. Evaluate the specified loss. Compute output δ, then hidden δ values in reverse order. Form all weight and bias gradients. Average over the batch if the objective is a batch mean. Add the appropriate regularisation gradients. Apply clipping if used, then let the optimiser update all parameters. The next forward pass uses the new parameters.

For a batch of B columns, ∂J/∂W=(1/B)ΔAᵀ and ∂J/∂b=(1/B)ΣcolumnsΔ when each column’s loss is summed over outputs. Bias gradients sum because the same bias is reused for every example.

Where the numbers come from

The equations follow directly from the chain rule and affine-map derivatives. No empirical constants are involved. A gradient for one parameter has units of loss divided by that parameter’s units; the learning rate must convert it into an appropriate parameter displacement.

Failure mode

Backpropagation is the gradient computation, not the optimiser. Momentum and Adam use the same gradients but different update rules. Mixing updated downstream weights with old cached activations produces a gradient of no single consistent forward computation.

Try it before revealing the answer

If the input to a weight is zero, what is that example’s gradient for the weight?

Zero, because ∂L/∂w equals the destination delta times that input. The bias gradient may still be nonzero.

Why must a hidden delta include every outgoing path?

The loss depends on the hidden activation through all of them. The multivariable chain rule adds these contributions.

6.1 Gradient descent, batches and stability

In one line

Gradient descent moves opposite the local gradient; the learning rate decides whether that local advice remains useful over the whole step.

The problem

Knowing a downhill direction does not tell us how far to move. A step can cross a narrow valley and land at higher loss. Conversely, a very small step can make training appear stuck even when the gradient is correct. Batch size controls how much data informs each estimated direction.

Mechanism

The update is θₜ₊₁=θₜ−ηgₜ. Full-batch gradient descent uses gₜ=(1/N)Σ∇ℓᵢ over all N examples. Stochastic gradient descent (SGD), in the strict one-example sense, uses one example. Mini-batch descent averages B examples. In common usage “SGD” can also refer to the mini-batch optimiser; state the batch size when precision matters.

MethodExamples per updateDirection and cost
Full batchNLow sampling noise; potentially expensive updates
Single-example SGD1Cheap noisy updates; poor hardware utilisation in some settings
Mini-batchB between 1 and NVectorised work and a trade-off between noise and cost

One epoch is one pass through the training set. One iteration usually means one parameter update. If N=1,000 and B=64 with the final partial batch retained, there are ceil(1000/64)=16 updates per epoch. Dropping the final partial batch gives 15. Do not quote N/B without stating the remainder policy.

An exact stability calculation

For f(x)=x²+4x+1=(x+2)²−3, the optimum is x*=−2. The derivative is 2x+4, so the error eₜ=xₜ+2 follows eₜ₊₁=(1−2η)eₜ. Convergence requires |1−2η|<1, hence 0<η<1. At η=0.5 it reaches the optimum in one step. At η=1 it oscillates with unchanged error magnitude. Above one, the error generally grows.

This supplies a precise reachable failure case for the lab. The general multi-dimensional positive-definite quadratic condition is 0<η<2/λmax(H), where H is its Hessian. Deep-network curvature changes during training, so this is not a universal network learning rate.

Mini-batch noise can help exploration but does not promise escape from every saddle or local minimum. A falling training loss followed by explosive growth, as in 2026 Q6, suggests an excessive learning rate; investigate gradients and numerical stability too.

Where the numbers come from

The polynomial and η=0.1 come from 2025 Q7. The stability bound is derived for that polynomial alone. Batch-size arithmetic is an added example with its remainder policy stated.

Failure mode

Changing from mean loss to summed loss multiplies gradients by batch size, effectively increasing the step at the same η. Comparing optimisers without matching loss scaling can therefore be misleading.

6.2 Momentum, Nesterov and adaptive methods

In one line

Momentum smooths the update direction; adaptive methods also scale coordinates using their gradient history.

The problem

A steep direction and a shallow direction can coexist in one loss surface. Plain descent may bounce across the steep direction while crawling along the shallow one. Momentum accumulates consistent directions, while per-coordinate scaling changes how strongly each coordinate moves.

Mechanism

Let gₜ=∇J(θₜ). In the velocity convention used here, momentum is vₜ=βvₜ₋₁+gₜ and θₜ₊₁=θₜ−ηvₜ. Another common convention multiplies the new gradient by (1−β); its numerical learning rate must be interpreted accordingly. Nesterov evaluates the gradient at the look-ahead point θₜ−ηβvₜ₋₁, then uses that gradient in the velocity update. Do not mix a velocity that already contains η with a formula that multiplies by η again.

MethodAccumulator and updateLimitation
AdaGradGₜ=Gₜ₋₁+gₜ²; θ←θ−ηgₜ/(√Gₜ+ε)Denominator can grow until learning nearly stalls
RMSPropvₜ=ρvₜ₋₁+(1−ρ)gₜ²; θ←θ−ηgₜ/(√vₜ+ε)Still needs a base learning rate and decay choice
AdamFirst and second moments, bias-correctedAdaptivity does not remove tuning or guarantee convergence

All squares, divisions and square roots here are coordinatewise. AdaGrad’s smaller later steps are not the same as vanishing gradients inside backpropagation: the raw gradient can remain large while the effective step shrinks.

Adam, with the time index explicit

Start m₀=v₀=0. At update t≥1, mₜ=β₁mₜ₋₁+(1−β₁)gₜ and vₜ=β₂vₜ₋₁+(1−β₂)gₜ². Correct initialisation bias using m̂ₜ=mₜ/(1−β₁ᵗ) and v̂ₜ=vₜ/(1−β₂ᵗ). Then θ←θ−ηm̂ₜ/(√v̂ₜ+ε). The second moment is an average of squared gradients, not a centred variance.

For one scalar gradient g₁=2, β₁=0.9 and β₂=0.999, m₁=0.2 and v₁=0.004. Bias correction gives m̂₁=2 and v̂₁=4. The first update is approximately −η, rather than −2η. This is a useful hand calculation of what normalisation does.

AdaDelta maintains moving averages of both squared gradients and squared updates, using their root-mean-square ratio to set update scale. Its original formulation avoids choosing a global η, although implementations may expose one. It replaces AdaGrad’s ever-growing history with a decaying window.

The comparator applies several update rules to the same quadratic and initial point. It illustrates trajectory differences; it does not establish which method wins on real datasets. A shared numerical learning rate is not equally tuned for every method.

Momentum can carry a parameter past a minimum. Adaptive methods can diverge or generalise poorly with unsuitable settings. “Adaptive” or “accelerated” does not mean guaranteed global optimum.

6.3 Learning-rate schedules and practical training logic

In one line

An optimiser chooses how to use a gradient; a schedule changes the learning-rate scale over training.

The problem

Large early updates can make progress quickly but may oscillate near a solution. Very small updates from the start can waste time. A schedule changes η while preserving the optimiser’s core rule.

Mechanism

Step decay multiplies η by a factor at chosen milestones. Exponential decay uses ηₜ=η₀e⁻ᵏᵗ. Inverse-time decay uses η₀/(1+kt). Cosine decay over T steps uses ηmin+½(ηmax−ηmin)[1+cos(πt/T)]. At t=0 it gives ηmax; at t=T it gives ηmin. These endpoint checks catch formula mistakes.

Warmup starts below the intended rate and increases it over an initial window, for example ηₜ=ηmax·t/Twarm. It can reduce instability while activations and optimiser state are poorly established. It is not required for every model.

One-cycle schedules raise then lower the learning rate, often coordinating momentum in the opposite direction. Warm restarts periodically restart a decay cycle. A restart may help explore other regions, but returning to a basin does not prove that basin is good.

Keep the clocks separate

A schedule may step per batch or per epoch. A milestone of 10 means something different in those cases. A validation-triggered schedule reduces η after performance stalls; early stopping decides when to stop and which checkpoint to restore. They can coexist but perform different actions.

A training log should record training loss, validation loss, learning rate, gradient norm and checkpoint epoch. Compare losses using the same reduction and mode. Training-time dropout can make training loss noisier or even larger than validation loss, so a single inversion is not automatically a bug.

Where the numbers come from

No decay factor, warmup length or patience is universally correct. Select them with validation evidence and record the actual schedule. The equations define how their constants affect the run.

Failure mode

Repeatedly choosing settings after inspecting the test set turns it into another validation set. If training loss is high, rule out a bug or unsuitable learning rate before assuming the architecture is too small.

Try it before revealing the answer

For ηmax=0.1, ηmin=0 and a cosine schedule, what is η at T/2?

Is early stopping a learning-rate schedule?

No. It terminates training and restores a checkpoint. A schedule changes update size while training continues.

6.4 Gradient flow, initialisation and clipping

In one line

Keep signal scales reasonable at initialisation, then monitor and constrain large gradients during training.

The problem

Backpropagation multiplies Jacobians across layers or time. Products can shrink the signal until early parameters barely learn, or amplify it into destructive updates. Randomness breaks hidden-unit symmetry, but its scale matters too.

Mechanism

Identically initialised hidden units produce identical activations and, under symmetric connections, identical gradients. They remain copies instead of learning distinct features. Random weights break this symmetry. Biases can often start at zero because different weights already distinguish the units; every parameter need not be nonzero.

If z=Σⱼwⱼaⱼ and independent zero-mean terms have comparable variance, Var(z)≈n Var(w) Var(a). Weight variance proportional to 1/n helps maintain scale. Xavier/Glorot normal initialisation uses Var(w)=2/(fan_in+fan_out); its uniform version uses ±√[6/(fan_in+fan_out)]. He normal initialisation for ReLU uses Var(w)=2/fan_in, approximately compensating for the half of a symmetric signal removed by rectification.

These are approximations involving independence, centring and activation assumptions. They do not guarantee exactly unit variance in every layer or stability after training changes the weights.

Norm clipping

For gradient g and threshold τ>0, use g·min(1,τ/‖g‖₂). If the norm is below τ, leave it alone. For g=[6,8], norm is 10. At τ=5, the result is [3,4], preserving direction and setting length to five. Clipping each component to [−5,5] instead gives [5,5], changing direction.

Clip after the complete backward pass and before the optimiser update. Clipping limits a gradient, not necessarily the eventual displacement under momentum or adaptive state. It cannot repair a vanishing gradient by making it larger. Normalisation, activation choice, short gradient paths and gated memory address other parts of the problem.

Where the numbers come from

The initialisation factors come from variance propagation approximations. The clipping threshold five is the course’s example, not a universal safe value. For fan_in=100, He variance is 0.02 and standard deviation is √0.02≈0.141421.

Failure mode

Clipping on nearly every step can conceal an excessive rate or bad scaling. Inspect unclipped norms too. A recurrent weight above one does not alone prove exploding gradients; activation derivatives and matrix directions matter.

6.5 Batch normalisation, training and inference

In one line

Batch normalisation standardises features using batch statistics during training, then applies learned scale and shift.

The problem

Changing earlier activations can make later-layer optimisation harder. Batch normalisation (BN) controls scale and can improve optimisation. Its original “internal covariate shift” motivation is not a complete settled explanation; the algorithm matters more than the slogan.

Mechanism

For one feature across x₁,…,xB, compute μB=(1/B)Σxᵢ and vB=(1/B)Σ(xᵢ−μB)². Then x̂ᵢ=(xᵢ−μB)/√(vB+ε), and yᵢ=γx̂ᵢ+β. γ and β are learned per feature. Running means and variances are inference state, not ordinary gradient-trained parameters.

For [2,4,6,8], μ=5 and v=5. Ignoring tiny ε for hand arithmetic, normalised outputs are [−1.341641,−0.447214,0.447214,1.341641]. With γ=2, β=1 they become [−1.683282,0.105573,1.894427,3.683282]. The affine transform lets the layer choose a useful scale rather than forcing its final outputs to have zero mean and unit variance.

Why evaluation mode matters

During training, one example’s output depends on others in its batch. At inference, stored running estimates are typically used so predictions do not depend on arbitrary accompanying examples. Dropout is also disabled at inference, for a different reason. Train/evaluation mode therefore affects more than gradient recording.

7.1 Underfitting, overfitting and polynomial interpolation

In one line

Report both training and held-out error: a model can fail by missing the signal or by fitting noise too closely.

The problem

A flexible model can reduce training error to zero while predicting poorly elsewhere. A simple model can miss the pattern even in training. The 2026 rubric rewards a sketch and both error descriptions for each case; “poor generalisation” alone is not the complete answer.

Mechanism

Underfitting means the learned function fails to capture relevant structure. Typical symptoms are high training error and high validation/test error with a small gap. Causes include insufficient capacity, weak features, excessive regularisation or unsuccessful optimisation. Overfitting means the fitted function depends too heavily on the training sample’s idiosyncrasies. Typical symptoms are low training error and substantially larger held-out error.

Bias is the difference between the average prediction over repeatedly sampled training sets and the true regression function. Variance describes how much the prediction changes across those sets. Under squared-error assumptions, expected prediction error decomposes into squared bias, variance and irreducible noise. This is a repeated-sampling statement at an input, not something calculable from one training loss alone.

The polynomial question

For N distinct scalar inputs, an unregularised polynomial of degree at most N−1 can interpolate any N targets in exact arithmetic. With noisy targets, it may oscillate and generalise poorly. A degree too small gives high training and test errors. As degree approaches N−1, training error can approach zero while test error is often high. This is not inevitable for every noiseless dataset; answer in the noisy-data setting illustrated by the paper.

7.2 L1, L2, elastic net and weight decay

In one line

Regularisation changes which low-error solution is preferred; its strength is selected with held-out evidence.

The problem

Many parameter settings can fit the same data. A penalty encodes a preference for smaller or sparser coefficients. If too strong, it prevents fitting real signal.

Mechanism

Let J=Jdata+λΩ(w), usually excluding biases by a stated choice. For Ω=½Σw², the gradient contribution is λw. Plain SGD gives wnew=(1−ηλ)w−η∇Jdata. This links squared-L2 regularisation and multiplicative weight decay for this optimiser.

For L1, Ω=Σ|w| and its derivative away from zero is sign(w). A proximal update takes u=w−η∇Jdata, then applies wnew=sign(u)max(|u|−ηλ,0). This soft-thresholding produces exact zeros. Fixed-step subgradient descent can bounce across zero instead; distinguish a property of the optimum from a property of every algorithm.

For ½(w−a)²+λ|w|, the exact optimum is sign(a)max(|a|−λ,0). For ½(w−a)²+(λ/2)w², it is a/(1+λ). The lab compares these exact scalar solutions rather than claiming to train a full network.

L∞Control largest coefficientValid but less common; focuses on maximum magnitude

Elastic net can be written λ[α‖w‖₁+(1−α)‖w‖²₂/2]. α=1 is pure L1; α=0 is pure L2. Other conventions scale these terms differently. Write the actual objective.

For adaptive optimisers, adding λw to the gradient sends it through the adaptive scaling. Decoupled weight decay applies a separate shrinkage operation. They are therefore generally different under Adam, even though the plain-SGD equivalence is correct.

Select λ using validation or cross-validation. Larger λ often increases bias and decreases variance. Feature scaling matters because coefficient magnitudes depend on units. λ=0 removes this explicit penalty, not every implicit training preference.

Where the numbers come from

If the penalty is λΣw² instead of (λ/2)Σw², its derivative is 2λw. The lab uses exactly the half-square convention. For a=0.3 and λ=0.5, L1 yields zero; L2 yields 0.2.

Failure mode

Increasing regularisation can worsen an already underfitting model. L2 does not forbid exact zero coefficients, and L1 does not guarantee sparsity under every optimisation method and dataset.

7.3 Dropout, augmentation and soft targets

In one line

Training-time perturbations discourage fragile reliance on individual features, units or exact labels.

The problem

A network can exploit accidental patterns absent from new data. Regularisation can perturb the data and intermediate representations, but the perturbation must preserve the intended task.

Mechanism

For inverted dropout with keep probability q, sample mⱼ from Bernoulli(q) and use ãⱼ=mⱼaⱼ/q in training. Since E[mⱼ]=q, E[ãⱼ]=aⱼ. At inference use a unchanged. The older convention uses mⱼaⱼ in training and scales contributions by q at inference. Both can be coherent; mixing them double-scales the signal. Distinguish drop probability p from keep probability q=1−p.

For scalar a, inverted dropout variance is a²(1−q)/q. At q=0.5, retained activations double and about half are zero. Exactly half need not disappear in each mask. The Monte Carlo lab compares a reproducible sampled mean with the exact expectation.

Augmentation and label smoothing

Translations, crops and reflections can increase observed image variety if labels remain valid. Reflection may suit a cat photo but not a text-recognition or directional task. Apply augmentation in the training pipeline and evaluate under a declared consistent policy.

Input noise can teach local robustness, as in denoising autoencoders. For K classes, uniform-mixture label smoothing sets ỹ=(1−ε)y+ε/K. The correct class gets 1−ε+ε/K and each other class ε/K. Some formulations distribute ε only among incorrect classes; do not mix conventions.

Dropout resembles training overlapping thinned networks with shared weights. Inference scaling approximates ensemble behaviour for nonlinear networks; it is not an exact average of every possible network output. Dropout can slow convergence and is not automatically useful in every architecture.

Where the numbers come from

n units admit 2ⁿ binary masks, with probabilities depending on q. For a=2,q=0.5, possible outputs are 0 or 4, mean 2 and variance 4. These are distributional facts rather than performance claims.

Failure mode

Leaving dropout enabled in ordinary inference makes predictions random. Tiny q produces large retained activations and noisy updates. Augmentation that changes the correct label teaches contradictory supervision.

7.4 Early stopping, ensembles and honest evaluation

In one line

Use validation to make decisions, restore the best checkpoint, and reserve test data for final assessment.

The problem

Training can keep improving its own objective after generalisation deteriorates. Multiple models can reduce variance only if their errors differ. Evaluation must distinguish real improvement from repeated tuning on held-out outcomes.

Mechanism

Early stopping monitors a validation metric at declared intervals, stores improvements and stops after a patience window without improvement. Restore the best checkpoint. For validation losses [0.8,0.6,0.5,0.52,0.54] and patience two, the best epoch is three; stopping occurs after five under the usual consecutive-non-improvement convention.

Bagging trains on bootstrap samples and averages predictions or votes. A bootstrap sample draws N times with replacement from N observations. The probability an observation is omitted is (1−1/N)ᴺ≈e⁻¹, so about 63.2% of distinct observations appear. The sample still contains N rows counting duplicates.

For k model errors with common variance V and pairwise covariance C, the variance of their average is V/k+(k−1)C/k. If C=0 it decreases as 1/k; if C=V, averaging gives no variance reduction. This is not a formula for total prediction error including bias.

Boosting builds models sequentially to correct mistakes or residuals, depending on the algorithm. Bagging members can train independently; boosting depends on earlier members. Chasing noisy labels can hurt boosting. Averaging identical models creates no new information.

Evaluation as part of the model

Split by independent entities, such as patients rather than near-duplicate scans. For forecasting respect time order. Fit scalers, vocabularies and feature selection on training data. Tune on validation. Report a final test result with the split and metric definitions.

Accuracy=(TP+TN)/N can hide rare-class failure. Precision=TP/(TP+FP) measures how many predicted positives are real; recall=TP/(TP+FN) measures how many actual positives are found. F1=2PR/(P+R) when defined. Predicting the majority class on a 95:5 dataset gives 95% accuracy but zero minority recall. Select a decision threshold without peeking at test outcomes.

Where the numbers come from

Patience two counts completed checks without improvement. The bootstrap fraction is an asymptotic expectation. Neither is a universal training recommendation.

Failure mode

To resume training reproducibly, preserve optimiser and schedule state along with weights. For final evaluation, restore the best model and use evaluation mode. The last epoch and best epoch need not coincide.

Try it before revealing the answer

Why can perfectly correlated ensemble errors defeat averaging?

They move together, so averaging cannot cancel them. Substituting C=V leaves variance V.

Why can validation loss be lower than training loss?

Training may include dropout, augmentation or penalties absent in evaluation, or the validation data may be easier. Check definitions and modes before concluding there is an error.

8.1 Encoder, bottleneck and decoder

In one line

An autoencoder reconstructs its input through a learned representation; the constraint makes that representation useful.

The problem

Unlabelled data still contain structure. An autoencoder creates a training target from the input itself: reconstruct x from a code h. Without a capacity or regularisation constraint, a powerful network can simply copy the input and learn little that transfers.

Mechanism

Write h=g(Wx+b) and x̂=f(W′h+c). The encoder produces the latent code; the decoder reconstructs the input. Train both using a reconstruction loss. For real-valued inputs, a linear output and squared error are common. For binary inputs, sigmoid outputs and binary cross-entropy model each coordinate as Bernoulli. Match the likelihood to the values: a greyscale intensity in [0,1] is not literally a binary variable merely because it is bounded.

An undercomplete autoencoder has fewer latent coordinates than input coordinates. An overcomplete one has more. Undercompleteness limits the channel through which information passes, but a highly expressive nonlinear encoder/decoder can still memorise training examples. Overcomplete models need constraints such as sparsity, denoising or contraction to avoid a trivial identity solution.

Count a small model

For d inputs and h latent units, an untied single-hidden-layer autoencoder has hd+h encoder parameters plus dh+d decoder parameters, total 2dh+h+d. If W′=Wᵀ, weights are tied and the count is dh+h+d. The decoder still has its own d biases unless the architecture says otherwise. Tying constrains the model and shares learning signals between encoder and decoder uses.

For d=4,h=2, untied count is 16+2+4=22; tied count is 8+2+4=14. Reducing parameter count is not identical to reducing code dimension: tying affects weights, while the bottleneck affects representation size.

Applications include compression, feature learning, denoising, imputation under a suitable masking objective, and anomaly scoring by reconstruction error. A low-dimensional code is a learned representation, not automatically a disentangled or interpretable one. A standard deterministic autoencoder also lacks a guaranteed useful distribution for randomly sampling its latent space; generative variants add further structure.

Where the numbers come from

The count follows the declared dense encoder/decoder and includes biases. The four-to-two example is added practice. Reconstruction error must specify whether it is a sum or mean over coordinates and samples.

Failure mode

An anomaly can reconstruct well if the model is too flexible or the anomalous pattern resembles its training data. Select thresholds on appropriate held-out evidence; do not treat reconstruction error as proof of anomaly.

Try it before revealing the answer

Is the target absent when training an autoencoder?

No. There is no external human class label, but the original input supplies the reconstruction target.

Does a two-dimensional bottleneck guarantee interpretable axes?

No. It constrains dimension, not semantic meaning. Many equivalent coordinate systems can encode the same information.

8.2 Linear autoencoders and principal components

In one line

An optimally trained linear squared-error autoencoder recovers a principal subspace, not necessarily the same individual coordinates as PCA.

The problem

The course connects autoencoders with principal component analysis (PCA), but “equivalent” needs conditions. A nonlinear autoencoder can learn a curved representation; a linear one has a restricted reconstruction map. Understanding the special case separates the shared geometry from the extra expressive power.

Mechanism

Centre the data by subtracting the training mean. PCA chooses orthonormal directions capturing maximal variance, equivalently minimising squared reconstruction error of an orthogonal low-rank projection. If the top h directions form columns of Q, the code is Qᵀx and reconstruction QQᵀx, with the mean added back afterwards.

A linear encoder and decoder with an h-dimensional bottleneck produce x̂=DE x. Minimising squared reconstruction loss to a global optimum recovers the principal h-dimensional subspace under the usual rank conditions. However, replacing E by RE and D by DR⁻¹ for invertible R leaves DE unchanged. The learned code need not be orthogonal or equal to the conventional ordered principal-component scores. Extra constraints are needed to identify those coordinates.

A two-dimensional projection you can compute

For unit direction u=[cos θ,sin θ]ᵀ, encode x as h=uᵀx and reconstruct x̂=uh. If x=[2,2] and θ=45°, h=2√2 and x̂=[2,2], giving zero reconstruction error. If θ=0°, h=2 and x̂=[2,0], giving squared error four. The best direction for a dataset depends on the covariance of all its centred points, not on one example alone.

The lab rotates a one-dimensional tied linear autoencoder over a fixed centred cloud. It calculates each projection and reconstruction and compares total squared error. It is a transparent geometric instance of the linear case, not a claim that arbitrary nonlinear autoencoders are PCA.

Where the numbers come from

Unit-length u ensures the decoder u and encoder uᵀ define an orthogonal projection. Without normalising u, uuᵀ is generally not that projection. A repeated largest eigenvalue makes the optimal direction nonunique within its eigenspace.

Failure mode

“Normalise” is ambiguous: centring and standardising every feature to unit variance are different operations. Standardising changes the PCA geometry. State the preprocessing and fit it only on training data.

8.3 Denoising, sparse and contractive autoencoders

In one line

Denoising changes the input task, sparsity limits activity, and contraction limits sensitivity of the code.

The problem

A wide code can copy almost every input detail. Different regularisers prevent this in different ways. Treating them all as “add L2” misses what each method constrains and what must be calculated in a numerical question.

Mechanism

A denoising autoencoder receives a corrupted input x̃ but is trained against the clean x. Its objective averages ℓ(x,decoder(encoder(x̃))) over the corruption process. For masking noise, each coordinate is set to zero with a specified probability. If the reconstruction target is changed to the corrupted input, a copying solution becomes attractive again and the denoising task is lost.

A sparse autoencoder penalises frequent hidden activation. For sigmoid hidden unit j, let ρ̂ⱼ be its average activation across training examples and ρ a small desired activation. A common penalty is βΣⱼKL(ρ‖ρ̂ⱼ), where KL=ρ ln(ρ/ρ̂)+(1−ρ)ln[(1−ρ)/(1−ρ̂)]. This nonnegative penalty is zero at ρ̂=ρ and grows as activity deviates. It constrains average activation, not necessarily sparsity of the weight matrix.

A contractive autoencoder penalises the encoder Jacobian J_h(x)=∂h/∂x using λ‖J_h(x)‖²F. It makes nearby inputs produce similar codes locally. For hⱼ=σ(wⱼᵀx+bⱼ), ∂hⱼ/∂xₖ=hⱼ(1−hⱼ)wⱼₖ. Therefore the squared Frobenius penalty is Σⱼ[hⱼ(1−hⱼ)]²Σₖwⱼₖ². Both weights and activation state affect sensitivity.

9.1 Convolution, cross-correlation and learned filters

In one line

A convolutional layer applies a small shared detector across spatial positions and sums its responses over input channels.

The problem

A dense layer on an image ignores the fact that nearby pixels form local patterns and that the same pattern can occur in different places. Connecting every pixel to every output also creates many parameters. Local connectivity and weight sharing encode a useful image prior.

Mechanism

For the operation commonly called convolution in neural networks, output at position (r,c) and channel o is a bias plus ΣᵢⱼₖK[o,k,i,j]X[k,r+i,c+j], adjusted for stride and padding. Most implementations perform cross-correlation, leaving the kernel unflipped. Mathematical convolution reverses its spatial axes. The supplied numerical example explicitly says weights are not flipped, so follow cross-correlation there.

A greyscale filter spans one channel. A colour-image filter spans all input channels, for example a 5×5×3 block. At each location, its 75 products are summed to one scalar plus bias. Six different filters produce six output channels, not eighteen. Each filter learns its own weights, but reuses them at every spatial location.

9.2 Output dimensions, padding and parameter counts

In one line

Output shape counts valid window positions; parameter count counts the reusable kernel coefficients.

The problem

Stride and padding change how many locations are evaluated, while filter count changes output depth. These are separate from the number of trainable coefficients. Confusing output activations with parameters is one of the most frequent convolution arithmetic errors.

Mechanism

For input extent N, kernel extent F, symmetric zero padding P, dilation D and stride S, effective kernel extent is Feff=D(F−1)+1. The output extent under the floor convention is floor[(N+2P−Feff)/S]+1, provided the kernel fits the padded input. Use the formula separately for height and width.

For ordinary convolution with Cin input channels and Cout filters, parameter count with bias is (FhFwCin+1)Cout. Stride, padding and input image width do not change this count. They change activations and computation. For grouped convolution with G groups, Cin/G replaces Cin for each output filter, provided both channel counts are divisible by G; this is an extension useful when comparing historical implementations.

The course shape example

Input 32×32×3, filter 5×5, S=1, P=0, six filters: output height and width are (32−5)/1+1=28, giving 28×28×6. Total activations are 4,704. Parameters are (25×3+1)×6=456. Those values answer different questions.

Add P=2 and the output becomes 32×32×6 with the same 456 parameters. Set S=2 with P=0 and output is floor(27/2)+1=14 in each spatial direction. A “same” padding mode may add asymmetric padding when strides or even kernel sizes require it; do not assume its policy is always one equal P on every side.

Compute cost versus storage

Ignoring bias additions, each output needs FhFwCin multiply-accumulate contributions. Multiply by HoutWoutCout for a rough operation count. This grows with output map size even though the parameter count does not. Training additionally stores activations, gradients and optimiser state, so raw parameter bytes alone do not predict training memory.

The 32×32×3 example is merged p. 606. Dilation defaults to one in the course examples. The floor is essential when the stride does not evenly divide the available span.

If N+2P<Feff, there are no valid output positions under this operation. The lab reports an invalid geometry instead of a negative tensor size. Pooling layers have no learned filter weights in the usual max/average forms, despite having window and stride hyperparameters.

9.3 Pooling and gradient routing

In one line

Pooling summarises a local region; max pooling routes its gradient to a selected maximum rather than learning a filter.

The problem

Later layers can become expensive if every spatial response is retained at full resolution. Pooling reduces spatial extent and provides some robustness to small shifts, while discarding information that may matter for precise localisation.

Mechanism

Max pooling selects the largest value in each window. Average pooling takes its mean. Channels are typically pooled independently, so a 2×2 spatial pool does not collapse output depth. Window size, stride and padding determine shape using the same valid-position reasoning as convolution.

Apply 2×2 max pooling with stride one to the stride-one feature map from the convolution example. The windows give max(−4,−4,−4,−4)=−4, max(−4,−1,−4,6)=6, max(−4,−4,5,5)=5, and max(−4,6,5,5)=6. Output is [[−4,6],[5,6]]. A maximum can be negative when all values in its window are negative.

If convolution first uses stride two, its 2×2 map is [[−4,−1],[5,5]]. One 2×2 max-pooling window gives [5]. The result differs because strided convolution sampled different patches before pooling. The pipeline order matters.

Backward pass

For a unique maximum, the upstream gradient is passed to the corresponding input position; all other positions receive zero from that window. For average pooling over k entries, each receives 1/k of the upstream gradient. Overlapping windows add their contributions when they reach the same input. Ties in max pooling require a specified subgradient/index convention, commonly choosing one recorded maximum.

Pooling can make a representation less sensitive to some small translations, but it does not guarantee exact translation invariance. Stride, image boundaries, aliasing and changes in which value wins can alter the result. For segmentation, aggressive pooling can remove the spatial detail needed for accurate boundaries.

Where the numbers come from

All displayed maps follow merged pp. 607–611. A 2×2 pool with stride one on a 3×3 map yields 2×2; stride two on that same map yields 1×1 under the floor convention. Overlapping pooling is valid and is used in this worked example.

Failure mode

Assuming every pool uses stride equal to window size gives the wrong answer when the paper specifies overlapping windows. Assuming max pooling always outputs nonnegative values silently inserts a ReLU.

9.4 Receptive fields and translation equivariance

In one line

Local layers accumulate a larger receptive field, while shared weights make translated patterns produce correspondingly translated responses.

The problem

A single 3×3 detector sees only a small neighbourhood. A classifier must eventually combine evidence over larger shapes. Stacking local layers expands what each later unit can depend on without immediately using a dense connection to every pixel.

Mechanism

Let r be receptive-field size and j the spacing, measured in original input pixels, between neighbouring outputs. Start r₀=1,j₀=1. For a layer with effective kernel Feff and stride S, update rnew=r+(Feff−1)j and jnew=jS. Apply the old j when updating r. Padding affects position and boundary content but does not change this theoretical interior receptive-field extent.

Three stride-one 3×3 convolutions give receptive fields 3,5,7. At constant channel width C, their kernel weights total 3·9C²=27C², versus 49C² for a single 7×7 convolution, ignoring biases. The stack also inserts extra nonlinearities. If channel widths differ, recompute the counts rather than using this shortcut.

For a 3×3 convolution, then 2×2 stride-two pool, then another 3×3 convolution: r progresses 1→3→4→8, while j progresses 1→1→2→2. The final units see an eight-pixel span even though no kernel is larger than three. This is a useful exam-style architecture calculation.

Equivariance is not invariance

A transformation T and function f are equivariant when f(Tx)=T′f(x), where T′ is the corresponding output transformation. For ideal stride-one convolution away from boundary effects, translating input translates its feature map. Invariance would mean f(Tx)=f(x): no output change. Classification may seek invariance; segmentation usually needs spatial equivariance.

Striding only preserves a restricted alignment relationship and padding introduces edge effects. A theoretical receptive field describes possible dependence, not how strongly trained weights actually use each pixel. The effective influence can be concentrated in only part of that field.

Where the numbers come from

The 3→5→7 growth assumes stride one and dilation one. The parameter comparison assumes C input and output channels for all compared layers. These assumptions are essential to the result.

Failure mode

Multiplying kernel sizes, such as 3×3×3=27, does not give the receptive-field width of three stride-one 3×3 layers. Use the recurrence. Calling all convolutional networks translation-invariant ignores boundaries, stride and final readout.

10.2 AlexNet, ZFNet and VGG: what changed?

In one line

These designs show how to train nonlinear visual features, inspect lost information and compose small filters deeply.

The problem

Making image models wider or deeper increases optimisation and generalisation difficulties. Architectural changes solve specific problems rather than merely add layers.

Mechanism

AlexNet’s course treatment emphasises rectified linear units, data augmentation and dropout in the dense classifier. ReLU avoids positive-side saturation, augmentation exposes more appearances, and dropout discourages reliance on particular units. 10.3 Inception, 1×1 bottlenecks and global average pooling

In one line

Inception processes spatial scales in parallel while 1×1 bottlenecks control channel cost.

The problem

Useful image features occur at different scales. Applying several filters in parallel captures them, but large filters across many input channels are expensive.

Mechanism

A 1×1 convolution mixes channels at each spatial position. For H×W×C input and B output filters, it gives H×W×B at stride one, with (C+1)B parameters. Its spatial field is one pixel, but its channel transformation can be useful. A following nonlinearity adds expressive power.

For a 5×5 branch mapping 192 channels to 32, direct weights total 25×192×32=153,600 plus 32 biases. Insert a 1×1 reduction to 16: weights are 192×16=3,072, then 25×16×32=12,800. Including 16+32 biases gives 15,920 parameters versus 153,632 directly. The reduction constrains the intermediate representation and saves computation.

Parallel 1×1, 3×3, 5×5 and pooling branches can concatenate channels when spatial sizes match. Concatenation adds channel counts. Elementwise addition, used in residual blocks, requires matching shapes and does not concatenate.

Global average pooling

Average each channel of H×W×C over H and W to produce C values. Global average pooling (GAP) adds no learned weights. For 7×7×1024, flattening gives 50,176 inputs; GAP gives 1,024. A K-class dense head changes from (50,176+1)K to (1,024+1)K parameters.

GAP discards detailed spatial arrangement. That may suit classification but not precise localisation without another spatial prediction head. Compression always removes some information; choose what the task can afford to lose.

Where the numbers come from

The 192→16→32 arithmetic is added practice illustrating merged pp. 631–634. Final totals include biases; intermediate quantities called weights exclude them.

Failure mode

A bottleneck too narrow loses useful information. Branch outputs cannot concatenate as intended if heights or widths differ; fix stride/padding alignment first.

10.4 Residual connections and transfer learning

In one line

A residual block learns a correction to a shortcut; transfer learning reuses learned features for a new task.

The problem

Adding layers can make optimisation harder even when the larger network can theoretically represent the smaller one. Separately, training a large image model from scratch may waste useful features already learned elsewhere.

Mechanism

A shape-preserving residual block uses y=x+F(x;W), possibly followed by an activation depending on the variant. A near-identity desired map can use a small residual F. Before any following activation, the local derivative is I+∂F/∂x, providing a direct gradient contribution through the shortcut.

When dimensions change, use a compatible projection, y=Ws x+F(x). Count its parameters. A 1×1 projection from 64 to 128 channels has 8,192 kernel weights, plus bias if present. Stride must align both paths. Elementwise addition requires equal shapes.

Residual paths often ease optimisation but do not guarantee a nonvanishing total gradient: paths can cancel, activations can gate and other Jacobians remain. The original motivation addresses degradation of training performance with depth, not only overfitting.

Reuse a pretrained representation

Feature extraction freezes the pretrained base and trains a new head. Fine-tuning also updates selected base layers. Both are transfer learning; the lecture’s comparison uses “transfer learning” in the narrower frozen-base sense.

Match the expected input preprocessing, replace and train the head, then optionally unfreeze later layers with controlled updates. Early visual features often transfer broadly; later features tend to be more task-specific. Choose the freeze boundary using domain similarity, data size and validation.

Freezing gradients and freezing batch-normalisation running statistics are different. A base whose statistics keep changing is not entirely frozen in behaviour. An overly aggressive fine-tuning rate can overwrite useful features.

Where the numbers come from

Identity shortcuts add no trainable coefficients when shapes match; projections do. No fixed fine-tuning rate ratio guarantees success.

Failure mode

Domain mismatch can make pretrained features ineffective. Repeated test-set tuning remains invalid even if most weights are frozen.

Try it before revealing the answer

Why does a residual block easily represent identity?

Its residual branch can approach zero, giving y≈x. A plain stack must learn a composition approximating identity.

Are fine-tuning and transfer learning mutually exclusive?

No. Fine-tuning is one transfer-learning strategy; frozen feature extraction is another.

11.1 Text as numbers: tokens, embeddings and masks

In one line

Token IDs are labels; embeddings turn them into learned vectors while sequence order preserves context.

The problem

Pixels already arrive as numbers, but words arrive as symbols. Assigning “cat=3” and “dog=4” does not imply dog is one unit greater than cat. A numerical representation must avoid imposing that false arithmetic while retaining the order needed to distinguish sentences.

Mechanism

Tokenisation divides text into characters, words or subwords. Character vocabularies are small but sequences are long; word vocabularies can contain many rare or unseen words; subwords reuse pieces. The actual split depends on a specified tokeniser. The lecture’s “un | happi | ness” is an illustration, not a universal split.

A vocabulary assigns an index to each token. One-hot encoding represents a token by a vector with one at its index and zeros elsewhere. Different tokens are orthogonal, so the code alone contains no learned semantic similarity. An embedding table E of shape V×d stores a learned d-vector per token. Looking up row i is equivalent to multiplying the one-hot row vector by E.

In the course’s small table, “cat” has index 3 and embedding [0.7,0.1,0.5]. Repeated occurrences retrieve the same base embedding; a recurrent network later gives those occurrences different context-dependent states. An embedding table with V=7,d=3 has 21 weights; V=50,000,d=300 has 15 million.

Batching variable-length sequences

Pad shorter sequences to a common T and supply a mask. After lookup, a batch has shape B×T×d. A mask should exclude padding positions from the loss and, when needed, from state updates or the chosen final-state readout. Merely setting pad embeddings to zero does not guarantee no state change, because recurrence and bias remain.

For next-token prediction, inputs and targets are offset by one: input “h e l l” targets “e l l o”. A vocabulary softmax at each step predicts a categorical distribution. Average cross-entropy only over actual target tokens, not padding. Perplexity is exp(mean negative log-likelihood) when natural logs are used. A uniform model over V tokens has loss ln V and perplexity V.

Bag-of-words loses order: “dog bites man” and “man bites dog” have the same counts. A sequence model distinguishes them by processing tokens in order. A numerical ID used for a proper embedding lookup is fine; the error is treating that ID as a meaningful scalar measurement.

Where the numbers come from

The seven-token embedding and character vocabulary follow merged pp. 676–694. Vocabulary size and embedding dimension are design choices, not fixed standards. Perplexity comparisons require the same tokenisation and evaluated data.

Failure mode

Building a vocabulary from the test set leaks information. Counting pad positions in the loss can reward a model for predicting padding instead of language. Truncating a sequence can remove its decisive evidence.

Try it before revealing the answer

Why can two identical tokens produce different recurrent states?

Their base embeddings are identical, but their previous hidden states differ, so the new state incorporates different context.

If mean cross-entropy is ln 4, what is perplexity?

4, equivalent to a uniform choice among four possibilities under that reference interpretation.

11.2 Recurrent state and a worked forward pass

In one line

A recurrent neural network updates a shared state from the current input and previous state, reusing one parameter set over time.

The problem

A fixed-size feedforward network does not naturally handle arbitrary sequence length or remember earlier inputs. A recurrent neural network (RNN) carries a state that summarises what has been processed. It does not have to retain every detail, and it may fail to preserve useful long-range information.

Mechanism

Using column vectors, a vanilla recurrent layer computes zₜ=Uxₜ+Whₜ₋₁+b and hₜ=tanh(zₜ). Output scores are oₜ=Vhₜ+c. Choose an output activation and loss for the task: linear for real-valued prediction, softmax for next-token classification, or sigmoid for a binary decision. Initial h₀ is often zero, but it can be learned or supplied from context if specified.

Unrolling draws one copy of the computation per time step. These are computational copies, not independent parameter sets. A network with 100 steps is deeper as a computation graph than one with two steps, while its trainable parameter count can stay unchanged.

An explicit scalar example

For x=[1,0.5,−1], U=0.5, W=0.8, b=0, h₀=0 and linear output yₜ=hₜ: z₁=0.5 and h₁=tanh(0.5)=0.462117. Next z₂=0.25+0.8(0.462117)=0.619694, giving h₂≈0.550915. Then z₃=−0.5+0.8h₂≈−0.059268, giving h₃≈−0.059199. The lab computes full-precision values and can remove or reverse the recurrent contribution.

If W=0, each state depends only on the current input and the model loses recurrence. If the same input repeats, states can still differ when W≠0 because their contexts differ. A large |W| can push tanh into saturation, so “stronger memory weight” does not automatically mean better long-term memory.

Parameters and layouts

For input dimension d, hidden dimension h and output dimension k, parameters are hd+h²+h+kh+k = h(d+h+1)+k(h+1). The course’s character model d=4,h=3,k=4 has 12+9+3+12+4=40. The count remains 40 for four or four hundred time steps.

Many-to-one uses a sequence to predict one label, such as sentiment. Aligned many-to-many predicts a label per input step, such as token tags. One-to-many generates a sequence from an initial condition. Unaligned many-to-many can use an encoder and decoder, as in translation. Choose the loss positions and state readout explicitly.

Where the numbers come from

The scalar numerical example is added practice with every parameter declared. The 40-parameter character count is the exact course example on p. 695. Reusing weights changes the count, not the number of arithmetic operations.

Failure mode

Carrying hidden state from one unrelated training sequence into another leaks context unless deliberately intended. Reset or detach state according to the batching/training design. A hidden state is a learned summary, not an exact stored transcript.

11.3 Backpropagation through time and shared gradients

In one line

Backpropagation through time adds error from current outputs and future states, then sums each shared parameter’s contributions over time.

The problem

A recurrent weight affects the current state and every later state that depends on it. Treating each time step as independent loses those paths. Treating the shared weight as a different parameter at every step trains a different model.

Mechanism

Let L=Σₜℓₜ, eₜ=∂ℓₜ/∂oₜ, and δₜ=∂L/∂zₜ. With tanh hidden state and oₜ=Vhₜ+c, the backward recursion is:

Open the equations / numerical layout
δₜ = [Vᵀeₜ + Wᵀδₜ₊₁] ⊙ (1−hₜ²)
∂L/∂U = Σₜ δₜ xₜᵀ
∂L/∂W = Σₜ δₜ hₜ₋₁ᵀ
∂L/∂b = Σₜ δₜ
∂L/∂V = Σₜ eₜ hₜᵀ
∂L/∂c = Σₜ eₜ

Start the final future contribution at zero. If there is no direct output loss at a time, its eₜ is zero, but δₜ can still be nonzero because future losses depend on that state. If the objective is a mean instead of a sum, include the normalisation once, consistently.

A two-step scalar derivative

Use U=0.5, W=0.8, x₁=1, x₂=0.5, h₀=0 and final-only loss L=½(h₂−1)². h₁=tanh(0.5); h₂=tanh(0.25+0.8h₁). δ₂=(h₂−1)(1−h₂²). Then δ₁=Wδ₂(1−h₁²). The recurrent gradient is δ₁h₀+δ₂h₁=δ₂h₁ because h₀=0. The input-weight gradient is δ₁x₁+δ₂x₂, with contributions from both times.

The lab exposes these deltas and checks ∂L/∂W by finite differences. A zero h₀ makes the first step’s direct W contribution zero, but the first state still affects later gradients. This is why visual unrolling and explicit sums are safer than memorising one multiplication.

Truncation and memory

Full backpropagation through time (BPTT) retains or recomputes the required forward states across the sequence. Truncated BPTT stops gradient flow at chosen boundaries while potentially carrying the forward hidden state onwards. Carrying state and carrying its gradient are different. Truncation reduces memory and computation but prevents learning credit assignments beyond the chosen gradient horizon in that update.

Teacher forcing, in a decoder setting, uses ground-truth previous tokens as training inputs. At generation time it uses its own previous predictions, creating a train/inference input mismatch. This is an additional sequence-training consideration, not a change to the chain rule.

Where the numbers come from

The scalar derivative problem is added practice with a final-only half-squared loss. Its equations are the same BPTT mechanism developed on merged pp. 698–724. The lab’s finite-difference ε is 10⁻⁵.

Failure mode

Updating W separately after every unrolled step while still claiming to calculate one full-sequence gradient mixes parameter versions. Accumulate the intended gradient before the update. Forgetting masks also propagates loss from padded targets.

11.4 Bidirectional context and gradient horizons

In one line

A bidirectional recurrent model reads both directions when future context is available; long gradient products remain a separate optimisation issue.

The problem

The meaning of an early token can depend on later words. A left-to-right state cannot see those words yet. For a complete observed sentence, a second recurrence can read backwards. For live next-token generation, that future information is unavailable.

Mechanism

Compute hᶠₜ=tanh(Uf xₜ+Wf hᶠₜ₋₁+bf) and hᵇₜ=tanh(Ub xₜ+Wb hᵇₜ₊₁+bb). Concatenate [hᶠₜ;hᵇₜ] for the output head. The backward recurrence starts at the end of the observed sequence and has its own parameters. “Bidirectional” is not the same as the backward derivative pass used for training every neural network.

For per-direction hidden width h, input d and output k, a simple bidirectional vanilla RNN count is 2h(d+h+1)+k(2h+1). With the course’s d=4,h=3,k=4, it is 2·24+4·7=76. Only the recurrent part doubles; the output head now receives 2h features.

Why memory fades in a vanilla recurrence

The Jacobian from hₜ₋₁ to hₜ is diag(1−hₜ²)W for tanh. Over many steps, the derivative contains a product of these Jacobians. Consistently small effective singular values attenuate the gradient; large expanding directions can amplify it. Scalar intuition: multiplying 0.8 fifty times gives about 1.43×10⁻⁵; multiplying 1.2 fifty times gives about 9,100.4. These numbers illustrate products, not a guarantee about a particular matrix network.

Gradient clipping addresses large gradients. Truncation reduces the number of multiplied steps but sacrifices long-range credit. Gated recurrent units and long short-term memory create controlled additive state paths, developed in Part 12. They improve the available mechanism without making every trained model remember indefinitely.

Use bidirectional context for tasks such as tagging a complete sentence or classifying a full recording. Do not let a backwards encoder see the future of a forecasting target and then report the result as a causal predictor. The available-information boundary is part of the task definition.

Where the numbers come from

The 76-parameter example follows merged pp. 696–697. The scalar powers are exact illustrative products rounded for display; real networks also involve varying derivatives and directions.

Failure mode

A bidirectional model can leak future information in an online task. Gating and bidirectionality solve different problems: controlled memory versus access to both sides of an observed sequence.

Try it before revealing the answer

Why can a bidirectional tagger use future words but a next-word generator cannot?

The tagger is given the whole observed sentence. The generator has not yet observed its future outputs.

Does a recurrent matrix norm above one prove explosion?

No. Activation derivatives and the directions traversed by the product also matter; a norm bound alone does not prove actual growth on every trajectory.

12.1 Long short-term memory: gate by gate

In one line

An LSTM maintains a cell state with an additive retain-and-write update, then controls how much of it is exposed as hidden output.

The problem

A vanilla recurrent state is repeatedly transformed by a full matrix and a squashing nonlinearity. Keeping an old fact unchanged through many steps is difficult. Long short-term memory (LSTM) adds an explicit cell state and gates that control what to retain, write and reveal.

Mechanism

Concatenate current input xₜ and previous hidden state hₜ₋₁ as vₜ. A common non-peephole LSTM has:

Open the equations / numerical layout
fₜ = σ(Wf vₜ + bf)          forget/retain gate
iₜ = σ(Wi vₜ + bi)          input/write gate
gₜ = tanh(Wg vₜ + bg)       candidate content
oₜ = σ(Wo vₜ + bo)          output/read gate
cₜ = fₜ ⊙ cₜ₋₁ + iₜ ⊙ gₜ
hₜ = oₜ ⊙ tanh(cₜ)

The gates f,i,o lie in (0,1) at finite logits. Candidate g lies in (−1,1). Cell state c can accumulate outside that range; tanh(c) and the output gate bound the exposed h. The candidate is sometimes called an update signal in slides, but it is distinct from the sigmoid input gate controlling how much of that signal is written.

One scalar cell, fully evaluated

Suppose cprev=0.8, f=0.9, i=0.2, g=0.5, o=0.7. The retained old content is 0.9×0.8=0.72. New content is 0.2×0.5=0.10. The next cell is c=0.82, and h=0.7tanh(0.82)≈0.47255. These gate values are supplied for arithmetic practice; a trained LSTM computes them from affine maps and activations.

If f≈1 and i≈0, the cell preserves old content. If f≈0 and i is large, it replaces much of that content. If o≈0, information can remain in c while very little appears in h. This distinction between storage and exposed state is what a one-state vanilla RNN lacks.

Counting parameters

For input dimension d and hidden/cell width h, each of four transformations receives d+h values and has h biases. Total is 4h(d+h+1), excluding a separate output head. With d=4,h=3, count is 4·3·8=96; a four-class head adds 4(3+1)=16, total 112. Implementations that store separate input and recurrent biases have a different stored-parameter count; state the one-bias-per-gate convention used here.

Where the numbers come from

The scalar gate values are an added worked example. The four-gate count follows the displayed non-peephole equations. Variants with peepholes, projections or coupled gates require a fresh count.

Failure mode

Sigmoid gates can saturate, and the cell can still forget useful information. LSTM does not guarantee unlimited memory or eliminate every vanishing/exploding gradient. It creates a trainable route that can preserve information when learned gates support it.

12.2 Gated recurrent units and update conventions

In one line

A GRU uses one state and two sigmoid gates, with the update gate blending old state and candidate content.

The problem

The LSTM has four learned transformations and two states. A gated recurrent unit (GRU) simplifies the mechanism while retaining a controlled path for old information. The main notation trap is that different sources assign opposite meanings to the update gate z.

Mechanism

This notebook uses the retain convention, matching the course’s description that z=1 keeps old state. With [xₜ;hₜ₋₁] as the gate input:

Open the equations / numerical layout
zₜ = σ(Wz [xₜ;hₜ₋₁] + bz)
rₜ = σ(Wr [xₜ;hₜ₋₁] + br)
gₜ = tanh(Ug xₜ + Wg(rₜ ⊙ hₜ₋₁) + bg)
hₜ = zₜ ⊙ hₜ₋₁ + (1−zₜ) ⊙ gₜ

The reset gate r controls how much previous state enters candidate construction. The update gate z blends the candidate with the old state. If z≈1, retain old content; if z≈0, use the candidate. Other texts write (1−z)hprev+zg, making z a write fraction. Both are valid with consistent definitions. Always inspect the equation before interpreting a gate value.

For scalar hprev=0.6, z=0.8, r=0.2, and an input contribution 0.5 with recurrent candidate weight one, g=tanh(0.5+0.2×0.6)=tanh(0.62)≈0.551128. Then h=0.8×0.6+0.2×0.551128≈0.590226. A small reset gate reduces old-state influence on the candidate, but a large update gate can still retain the old state directly.

Some formulations apply reset after a recurrent affine transform rather than before it. Matrix multiplication does not generally commute with elementwise gating, so these are distinct variants. The lab declares its scalar reset-before form; implementation-specific parameter counts may include separate biases.

For the displayed one-bias-per-transformation model, count is 3h(d+h+1), excluding the output head. With d=4,h=3, that is 72 rather than the LSTM’s 96. Fewer parameters can reduce cost, but do not imply universally better or worse accuracy. The task and training determine performance.

Where the numbers come from

The count is three affine transformations: update, reset and candidate. The scalar values are original practice, with every input contribution specified. Comparisons to LSTM hold d and h fixed.

12.3 Why additive memory helps—and where it still fails

In one line

Gated additive paths offer controllable gradient retention; they improve the mechanism without guaranteeing perfect memory.

The problem

A simple explanation such as “LSTM solves vanishing gradients” hides the conditions that make it work. The exam-level understanding should connect gate equations to gradient flow and distinguish the direct path from the full derivative through all dependent gates.

Mechanism

Along the direct LSTM cell-state path, holding gate values fixed, ∂cₜ/∂cₜ₋₁=diag(fₜ). Across multiple steps that path contributes a product of forget gates. If f≈1, the path can carry gradient with little attenuation. If f=0.9 at every step, its scalar contribution after 50 steps is 0.9⁵⁰≈0.005154; useful retention is not automatic. At f=0.99 it is about 0.605006.

The full derivative also contains effects through h and the gates, since their values depend on earlier state. Thus the direct-path product is an illuminating component, not the complete Jacobian of every LSTM variant. Output tanh and gate saturations can still constrain gradients, and exploding updates may still require clipping.

A GRU likewise has a direct old-state term z⊙hprev under the retain convention. This gives a controlled bypass of candidate computation. The reset gate governs candidate context, while the update gate determines how rapidly state changes. A large gate can preserve both useful information and irrelevant information; training must learn which is which.
